🔧 站点基础信息

📌 工作原理本站为纯静态网站，所有内容存在 content.js 一个文件里。编辑后「保存并预览」仅本机可见；「发布到GitHub」会把 content.js 和上传的媒体文件提交到你的仓库，GitHub Pages 自动更新上线。

🚀 GitHub 发布配置

GitHub → Settings → Developer settings → Personal access tokens → 生成经典Token，勾选 repo 权限。Fine-grained Token 则勾选目标仓库的 Contents: Read and write。
等待操作…

💾 备份与恢复

导出的文件也可手动放进仓库根目录覆盖 content.js 完成更新。

📏 媒体文件建议

  • 单文件 < 20MB（GitHub限制100MB，小文件加载更快）
  • 大视频建议先传到视频平台，粘贴分享/embed链接
  • 图片推荐 JPG/WebP，宽度 ≤ 1600px
  • 仓库总大小建议控制在 1GB 以内
